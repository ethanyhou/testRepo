# Calculator Project

A versatile calculator application designed to perform mathematical operations with ease and accuracy.

## Overview

This calculator project provides a reliable tool for performing basic and advanced mathematical calculations. Whether you need simple arithmetic or complex mathematical operations, this calculator is designed to meet your computational needs.

## Features

- **Basic Arithmetic Operations**
  - Addition, subtraction, multiplication, and division
  - Support for decimal numbers
  - Order of operations (PEMDAS/BODMAS)

- **Advanced Functions**
  - Percentage calculations
  - Square root and power operations
  - Memory functions (M+, M-, MR, MC)

- **User-Friendly Interface**
  - Clean and intuitive design
  - Clear display of calculations
  - Error handling for invalid operations

- **Additional Features**
  - Calculation history
  - Keyboard support
  - Clear/delete functions
